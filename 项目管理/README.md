## 完成证据怎么留

代码提交写 commit 链接或短哈希；测试写命令、结果和截图路径；文档写项目内相对链接。真实 API Key、`.env`、个人隐私信息不要放进日报、截图或仓库。共享进度表是对外登记，这里的日报是可追溯的组内明细。
