```text
2	时限7天，出处DOC-02-01，计算截止日	compute_return_deadline	sign_date=2026-12-01, window_days=7, basis_doc=DOC-02-01-普通…	Python 计算（日期加法）	DOC-02-01-普通商品退货规则.md

```

```text
计算工具是否适用（选做）：
  · 本组有没有数值：有：DOC-02-01 写着“签收后7天内”，CSV 里没有金额/时长字段
  · 算什么：签收日期 + 7 天 = 退货评估截止日期（纯日期加法）
  · 天数从哪来：必须由 search_knowledge 先查到资料原文，计算工具再核对原文里确有“N天”
  · 谁来算：Python 的 datetime 做加法；模型只提供签收日期，禁止口算日期
  · 算不出来怎么办：资料里查不到时限就直接回答资料不足，不做估算、不补默认值
  · 不适用会怎样：若本组只有文本没有数值（如纯政策问答），就不做计算工具，照实说明即可
结论：本组有真实数值（7 天时限 + 签收日期），计算工具**适用**；若换成只有政策文本的小组，就不做，并在文档里写明不适用。
```

关键约束是**天数必须来自资料**：`window_days=30` 会被拒，
因为 `DOC-02-01` 里没有“30天”这个写法；模型只提供签收日期，日期加法由 Python 做。

## 七、边界核对

下面每一条错误都由 Python 在**执行之前**或**拿到结果之后立即**拦下，
报错文案直接说明被拒绝的原因。

### 未知工具：模型提议了也执行不了

```text
停止原因：tool_rejected  工具调用：0 次  答案：''
拒绝原因：工具未授权：'delete_collection'；只有 ['search_knowledge', 'lookup_faq', 'compute_return_deadline'] 可以调用，模型只能提议，是否执行由 Python 决定
```

### 参数不合格式：不会被“顺手修正”后执行

```text
停止原因：tool_rejected  工具调用：0 次
拒绝原因：lookup_faq.question_id 格式不正确：'123'
```

### 注入串当编号：格式校验直接挡下

```text
ToolRejected: lookup_faq.question_id 格式不正确：'EC-FAQ-01; DROP TABLE faq'
```

### 计算工具的天数必须先在资料原文里出现

```text
ToolRejected: DOC-02-01-普通商品退货规则.md 里没有“30天”这个时限；计算参数必须来自已查到的记录
```

### finish 引用了没观察过的来源

```text
ValueError: 回答引用了未观察到的来源：DOC-02-99-不存在的资料.md；finish.sources 只能填写工具结果里出现过的数据来源
```

### 一次数据都没看到，却不肯说“资料不足”

```text
ValueError: 没有观察到任何数据时，回答必须包含“资料不足”
```

### SQLite 是只读打开的：写不进去

```text
OperationalError: attempt to write a readonly database
```

### max_steps 小于 2：看不到“行动后再决策”

```text
ValueError: max_steps 至少 2，要留出一次行动 + 一次答复
```

### 模型返回的东西不是 JSON

```text
ValueError: 模型未返回有效 JSON：好的，我先查一下资料。<这不是 JSON>
```
