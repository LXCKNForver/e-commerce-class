这一节要看的是三件事：第 1 轮模型**提议**检索、Python 真的去查、
观察回填进对话；第 2 轮模型看到资料后才把 action 改成 finish。
回答里每条结论都能指回清单上的文件——来源不是模型随口写的，是库里真有的。

## 四、限制最大轮次：未完成的停止状态（30–40 分钟）

```text
--- 轮次受限重跑（30–40 分钟）：max_steps=2
问题：普通商品签收后多久还能申请退货评估？另外商品有质量问题需要准备哪些材料？
停止原因：max_steps（轮次耗尽，尚未完成）
轮次上限：2  实际轮次：2  检索次数：2  决策调用：2
最终回答：（本轮未产出答案）

轨迹：普通商品签收后多久还能申请退货评估？另外商品有质量问题需要准备哪些材料？
轮次	决策说明	动作	查询	观察到的来源
1	问题含两个事项，先查退货时限	search_knowledge	普通商品签收后申请退货评估的时限	常见售后问题.csv、DOC-02-01-普通商品退货规则.md、售后受理材料清单.pdf
2	退货时限已查到，再查质量问题材料	search_knowledge	商品有质量问题申请售后需要准备哪些材料	常见售后问题.csv、售后受理材料清单.pdf、DOC-02-04-质量问题处理.md
第 2 轮结束后轮次耗尽：没有 answer，必须如实说明任务未完成，不能把已看到的片段拼成答案。
```

同一道题改成 `max_steps=2` 重跑：第 2 轮还在检索，轮次就耗尽了。
此时 `stop_reason=max_steps`，答案为空、来源为空，
必须如实告诉用户“尚未完成”，**不能把已经看到的片段拼成答案**——
这是完成任务的比例问题，不是答案质量问题。

## 五、轨迹对比：finished 与 max_steps

```text
轨迹对比：同一道题，只改最大轮次
场景	最大轮次	实际轮次	检索次数	停止原因	是否答复
双事项问题（18–30 分钟）	4	3	2	finished	是
轮次受限重跑（30–40 分钟）	2	2	2	max_steps	否（未完成，不予采纳）

结论：max_steps 从 4 降到 2 后，停止原因从 finished 变成 max_steps；后者必须如实标记为“尚未完成”，不得把半途观察到的片段当答案交付。
限制轮次不会让模型更谨慎，只会让它更早停下——这是成本约束，不是质量信号。
```

两点值得记住：限制轮次**只改变停在哪一轮**，不改变模型会不会多查一次；
轮次耗尽后不会再偷偷多问一次模型（`决策调用` 等于 `轮次上限` 就是证据）。

## 六、为什么模型只能提出动作、检索必须由 Python 执行

| 理由 | 说明 |
| --- | --- |
| 模型给不出向量 | 向量由本地中文模型算出，模型 API 返回不了 512 维向量，也拿不到库里的距离 |
| 隔离要靠 where | project_id 过滤在 Chroma 端执行，交给模型等于放弃项目边界 |
| 动作必须可信 | 白名单拦住未知动作；模型“提议删库”也只是个没人执行的字符串 |
| 引用必须真实 | finish 的来源由 Python 校验，没检索到过的一律拒绝放行 |
| 停止条件要可控 | max_steps 由 Python 计数，到点了就是未完成，不允许再来一次 |

一句话概括：模型负责“下一步干什么”，Python 负责“这一步真的发生了什么”。
把执行权交给模型，等于让看不见数据库的一方替另一方签字。

## 七、边界核对

下面每一条错误都由 Python 在**调用模型之前或之后立即**拦下，
报错文案直接说明被拒绝的原因。

### 动作不在白名单里：模型“提议”了也执行不了

```text
ValueError: 未知动作：'delete_collection'；只允许 ['search_knowledge', 'finish']，模型只能提议动作，是否执行由 Python 决定
```

### finish 引用了没检索到的来源

```text
ValueError: 回答引用了未检索到的来源：DOC-02-99-不存在的资料.md；finish.sources 只能填写工具结果里出现过的文件
```

### 一次资料都没看到，却不肯说“资料不足”

```text
ValueError: 没有观察到任何资料时，回答必须包含“资料不足”
```

### max_steps 小于 2：看不到“行动后再决策”

```text
ValueError: max_steps 至少 2，至少要留出一次行动 + 一次决策
```

### 没配密钥时不降级到本地脚本策略

```text
DeepSeekConfigError: 请先设置DEEPSEEK_API_KEY，或使用默认的Mock模式
```

### 模型返回的东西不是 JSON

```text
ValueError: 模型未返回有效 JSON：好的，我先查一下资料。<这不是 JSON>
```
